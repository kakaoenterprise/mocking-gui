# Security Policy

## Supported Versions

Only the latest minor release line of `@kakaocloud/mocking-gui` receives security fixes.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

> Mocking GUI is a **development-time** tool. It should never be bundled into production builds. See the `NODE_ENV === 'development'` guard in the [Quick Start](https://kakaoenterprise.github.io/mocking-gui/guide/quick-start).

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

- Preferred: open a private report via [GitHub Security Advisories](https://github.com/kakaoenterprise/mocking-gui/security/advisories/new).
- Alternatively, email [kc-oss@kakaoenterprise.com](mailto:kc-oss@kakaoenterprise.com).

We aim to acknowledge reports within 5 business days and to publish a fix or mitigation as soon as one is available.
